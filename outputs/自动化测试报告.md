## 3. Playwright Bridge 冒烟验证

在真实浏览器页面中使用 Playwright Bridge 完成了以下验证：

1. 首页正确加载，可识别运动筛选、赛事卡和底部导航。
2. 点击“足球”筛选后，点击 NBA 直播赛事卡可进入“比赛中心”。
3. 点击“客队看台”后，输入框提示更新为“在客队看台聊聊比赛...”。

冒烟验证结果：**通过**。

## 4. 缺陷与风险

本轮未发现应用功能缺陷。

测试配置阶段发现并修复了两项基础设施问题：

- 移动设备预设默认使用 WebKit，与 Chrome 通道冲突，已显式设置为 Chromium。
- 本机未安装 Playwright FFmpeg 组件，关闭非必要视频录制后不影响测试执行、截图和 Trace 能力。

当前测试尚未覆盖：

- 聊天消息真实发送与服务端持久化。
- 搜索、评论、收藏、通知等当前仅展示入口的功能。
- 账号登录、权限、内容审核与举报。
- 真实赛事数据、弱网、性能、跨浏览器和桌面响应式测试。

## 6. 建议

1. 接入真实后端后，优先补充登录、聊天发送、发帖评论与关注持久化用例。
2. 增加 API Mock 或测试环境数据种子，确保赛事与帖子数据稳定可重复。
3. 在 CI 中执行 `npm run test:e2e`，将 HTML 报告作为流水线产物保存。
4. 上线前补充 iOS Safari、Android Chrome、桌面 Chrome 的兼容性回归。
